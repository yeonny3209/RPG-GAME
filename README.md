# 잃어버린 왕관 (The Lost Crown)

견습 모험가 리오가 마왕에게 빼앗긴 「빛의 왕관」을 되찾아 오는 2D 탑다운 액션 RPG입니다.
웹 브라우저에서 바로 플레이할 수 있어요.

**▶ 플레이하기: https://yeonny3209.github.io/RPG-GAME/**

## 조작법

| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| 스페이스 / J | 공격 |
| E / Enter | 말 걸기, 상자 열기, 대화 넘기기 |
| 1 / 2 | HP 포션 / 마나 포션 빠르게 마시기 |
| Z / X / C / V | 스킬 (레벨이 오르면 배움) |
| I | 가방 (아이템 사용, 장비 장착) |
| Q | 퀘스트 목록 |
| M | 소리 켜기/끄기 |
| Esc | 메뉴 (저장, 조작법, 타이틀로) |

## 게임 내용

- 지역 6곳: 햇살골(마을), 속삭이는 숲, 수정 동굴, 마왕의 방, 그리고 선택 지역 2곳
  - **안개 늪** (숲 동쪽, 권장 레벨 3~5): 독두꺼비, 도깨비불, 약초꾼 할머니
  - **서리 봉우리** (마을 동쪽, 레벨 5 이상 입장): 눈 늑대, 얼음 정령, 중간 보스 「서리 골렘」
- 몬스터 8종 + 보스 2종 (「그림자 군주 모르그」, 「서리 골렘」)
- 레벨업(최대 15), 무기·방어구 장착, 상점, 보물상자
- 무기 7종: 무기마다 공격 방식이 다름 (단검은 빠르고 독, 창은 멀리, 도끼는 느리고 넓게)
- 스킬 4종 (MP 사용): 회전베기(Lv2), 파이어볼(Lv4), 치유의 빛(Lv6), 번개(Lv9)
- 메인 퀘스트 1개 + 서브 퀘스트 4개
- 여관 / 메뉴에서 저장, 맵을 이동할 때 자동 저장
- 플레이 시간 약 30~45분

## 직접 고쳐 보기

숫자와 대사는 코드와 따로 모아 두었어요. 아래 파일을 고치면 게임에 바로 반영됩니다.

| 파일 | 내용 |
|---|---|
| `src/data/monsters.js` | 몬스터 체력·공격력·경험치, 레벨업 경험치표 |
| `src/data/items.js` | 아이템 효과와 가격, 상점 목록, 무기별 공격 방식 |
| `src/data/skills.js` | 스킬 MP·위력·재사용 시간, 배우는 레벨 |
| `src/data/story.js` | NPC 대사, 퀘스트 |
| `src/data/maps.js` | 맵 (글자 하나가 타일 하나) |

## 내 컴퓨터에서 실행하기

브라우저 보안 때문에 `index.html`을 더블클릭하면 실행되지 않아요. 로컬 서버로 열어야 합니다.

```bash
python tools/serve.py 8124
```

그다음 브라우저에서 http://localhost:8124 을 엽니다.

- 주소 뒤에 `?debug`를 붙이면 개발용 단축키가 켜집니다: K(경험치 +50), G(골드 +500), N(무적), H(회복), T(다음 맵으로 이동)
- `node tools/check-maps.mjs`를 실행하면 맵에 막힌 길이 없는지 검사합니다.
